# Revive Salon Collective homepage concept

An independent, responsive homepage proposal by Dante Fabillar. This is a static design demonstration, not Revive Salon Collective's official website.

The concept uses Revive's existing public brand and suite photographs only to show the proposed design to the site owner. Images remain hosted on Revive's domain. Business facts are based on the public site as reviewed September 25, 2026. Verify details and obtain approval before using this design on the official site.

The inquiry and tour buttons direct to Revive's official contact page; there is no duplicate form collecting visitor data. Internal navigation scrolls to sections; other links lead to Revive's official website.

Run locally with `python -m http.server 4173` from this directory. It requires no build step and can deploy as a static site on Vercel.
